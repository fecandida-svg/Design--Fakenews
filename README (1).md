# 🔍 Combata a Fake News

> **Pense • Verifique • Compartilhe com responsabilidade**

![Campanha Combata a Fake News](Combata%20a%20Fake%20News%20no%20Escrit%C3%B3rio.png)

Projeto de conscientização sobre **desinformação**, **checagem de fatos** e **educação digital**. Este material reúne orientações práticas para identificar notícias falsas, verificar informações antes de acreditar nelas e compartilhar conteúdo com responsabilidade.

---

## 📌 Sobre o projeto

A desinformação se espalha rapidamente. Hábitos simples de leitura crítica e verificação ajudam a:

- Reconhecer sinais de notícias falsas;
- Verificar a origem de uma informação antes de acreditar nela;
- Evitar o compartilhamento de conteúdo enganoso;
- Promover a educação digital no dia a dia.

## ⚠️ Como identificar uma Fake News

| Sinal de alerta | O que observar |
|---|---|
| **Título sensacionalista** | Exageros, uso excessivo de letras maiúsculas e promessas chocantes. |
| **Sem fonte ou autor** | Não informa quem escreveu nem de onde vieram os dados. |
| **Apelo emocional forte** | Tenta provocar raiva, medo ou urgência. |
| **“Compartilhe antes que apaguem!”** | Pressiona o leitor a repassar o conteúdo sem pensar. |
| **Erros de português** | Texto mal escrito ou sem revisão pode ser um sinal de alerta. |
| **Imagens fora de contexto** | Fotos antigas ou relacionadas a outros acontecimentos. |
| **Site desconhecido** | Endereço que imita o de veículos de comunicação conhecidos. |

## ✅ Checklist: Pense → Verifique → Compartilhe

### 1. 🧠 Pense

- [ ] A notícia provocou uma emoção forte? Respire antes de reagir.
- [ ] Parece bom (ou ruim) demais para ser verdade?

### 2. 🔎 Verifique

- [ ] Quem publicou? A fonte é confiável?
- [ ] Outros veículos sérios noticiaram o mesmo fato?
- [ ] A data e o contexto estão corretos?
- [ ] Fiz uma busca reversa da imagem?
- [ ] Consultei uma agência de checagem?

### 3. 📤 Compartilhe com responsabilidade

- [ ] Só repasso informações que consegui confirmar.
- [ ] Se descobrir que uma informação era falsa, aviso quem a recebeu.
